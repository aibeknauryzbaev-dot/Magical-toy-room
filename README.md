# Ғажайып ойыншықтар бөлмесі
Іске қосу: `index.html` файлын браузерде ашыңыз (интернет, сервер қажет емес).
Деңгейлер: 1) Зат қайда? 2) Фигураны таны 3) Фигуралардан құрастыр 4) Қорытынды.
Ресурстар `assets/` ішінде (`reference.png` — бастапқы сурет). Сүйреу: тінтуір және сенсор.
Тапсырмалар `script.js` ішіндегі `SQ`, `BD`, `LV` массивтерінде өңделеді.
